> “你发射的不是弹药，而是地球未来的呼吸。”

一个基于经典《祖玛》玩法改造的环保主题化学反应游戏。  
玩家将在不断恶化的工业排放通道中，通过控制：

- 🔵 氧气（O₂）

来调节：

- ⚫ 碳（C）

- 🌫 二氧化碳（CO₂）

之间的化学反应，维持生态系统的“碳平衡”。

# 🕹️ 核心玩法

游戏由三个核心系统组成。

---

# 1️⃣ 发射系统

玩家只能发射：

| 元素 | 作用 |
|---|---|
| 🔵 O₂ | 制造燃烧 / 氧化 CO / 创造三消 |
| 💧 H₂O | 触发光合作用 / 净化 CO₂ |

---

## 插入机制

玩家点击轨道上的任意间隙：

```txt
球会被直接插入到两个元素之间
```

与传统祖玛不同：

- 不强调瞄准
- 不强调飞行轨迹
- 更强调：
  - 连锁设计
  - 污染管理
  - 化学规划

---

# 2️⃣ 化学反应系统

所有反应都会在插入后自动检测。

并支持：

# 🔁 连锁反应

---

## 🔥 燃烧反应

当：

```txt
C + O₂
```

相邻时：

```txt
→ CO₂
```

### 效果

- 消除碳堵塞风险
- 但会制造新的 CO₂ 污染

---

## ☁️ 一氧化碳氧化

新增危险元素：

# ☁️ CO（一氧化碳）

当：

```txt
CO + CO + O₂
```

连续相邻时：

```txt
→ CO₂ + CO₂
```

---

### 特点

CO 属于：

# “潜伏型污染物”

它本身危险较低，

但：

- 容易积累
- 会快速扩散
- 遇到氧气后会产生大量 CO₂

因此：

> 🔵 O₂ 并不总是安全的。

错误使用氧气，

可能导致：

- 污染爆发
- 连锁失控
- 通道崩溃

---

## 🌿 光合作用

当：

```txt
CO₂ + H₂O
```

相邻时：

```txt
→ O₂ + 🍎
```

### 效果

- 净化 CO₂
- 生成氧气
- 稳定生态系统

---

## 💥 三消系统

当：

```txt
≥3 个相同元素连续相邻
```

会自动消除。

---

### 三消作用

三消不仅是“清除球”。

它更重要的作用是：

- 压缩轨道
- 创造新的相邻关系
- 引发新的化学反应
- 重构污染结构

---

# 🔁 连锁机制

每次插入后，

系统都会循环检测：

```txt
三消 → 燃烧 → CO氧化 → 光合作用
```

直到系统稳定。

因此：

一次插入可能引发：

- 多次燃烧
- 多次净化
- 多段三消
- 大规模污染变化

---

# ☣️ 失败机制

轨道代表：

# 🏭 工厂排放通道

污染物会不断向终点推进。

---

## ⚫ 管道堵塞

当：

```txt
C 到达终点
```

会导致：

# 🚫 堵塞值 +1

---

## 🌫 污染泄露

当：

```txt
CO₂ 到达终点
```

会导致：

# ☣️ 泄露值 +1

---

## ❌ 游戏失败

以下任意达到上限：

| 危机 | 上限 |
|---|---|
| 堵塞值 | 3 |
| 泄露值 | 3 |

游戏失败。
