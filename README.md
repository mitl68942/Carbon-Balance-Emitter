# 🎮 碳平衡射手 · Carbon Balance Shooter (Demo)

> 一个 5 分钟可跑通的 MVP，验证“发射 → 反应 → 改变局势 → 再决策”的核心乐趣。  
> 玩法核心建立在经典游戏《祖玛》之上，用化学元素重新诠释消除与生存。

---

## ⚡ Demo 目标

这个 Demo **只验证一件事**：

**玩家是否能在“发射 → 反应 → 改变局势 → 再决策”的循环中获得乐趣。**

不包含分数、时间限制、商店或复杂升级，只保留最纯粹的化学连锁与危机管理体验。

---

## 🧩 核心玩法（最小闭环）

游戏只保留 **3 个系统**，形成完整闭环：

### 1️⃣ 发射系统（玩家操作核心）

- 玩家**只能发射两种球**：
  - 💧 **水 (H₂O)**  
  - 🔵 **氧气 (O₂)**  
- 点击轨道任意位置，即可将手中的球**直接插入**到目标位置的两个球之间。
- 可随时切换当前手牌球类型。

### 2️⃣ 三种反应（核心玩法）

反应在插入后自动检测，并支持**连锁触发**：

| 反应类型 | 触发条件 | 效果 |
|---------|----------|------|
| 🔥 **燃烧** | **C + O₂** 相邻 | 两者消失，生成 **CO₂**（二氧化碳） |
| 🌿 **光合作用** | **CO₂ + H₂O** 相邻 | 两者消失，生成 **O₂**（氧气） |
| 💥 **三消** | **≥3 个相同元素** 连续相邻 | 该组球消除，轨道收缩 |

- **CO₂ 是唯一的压力来源**：它会在轨道上向终点推进，必须尽快用光合作用消除。
- 三消用于清理轨道、压缩战线、创造反应空间。

### 3️⃣ 失败机制（唯一失败条件）

- 任何 **CO₂ 到达轨道终点** → **污染点 +1**
- 污染点达到 **3 点** → **游戏失败**

没有时间限制，没有 HP，生存压力完全来自玩家自己的决策与反应速度。

## 🕹️ 操作方式

| 操作 | 键鼠 |
|------|------|
| 切换手牌球 | 点击切换按钮 / 空格键 |
| 插入球 | 鼠标点击轨道上的目标位置 |
| 重新开始 | 游戏结束界面点击按钮 |

---

## 🎨 视觉与反馈

- 轨道采用螺旋/环形结构，从外围向中心延伸，终点位于最内部。
- 球以彩色圆形呈现，标注元素符号（C、H₂O、O₂、CO₂）。
- 插入、反应、连锁均有闪烁/缩放动画。
- 污染点以红色图标显示，每次增加伴随屏幕震动或警示闪烁。
- 游戏结束显示失败提示，并可直接重新开始。

---

## 🧪 初始状态

- 轨道上随机生成 **20~30 个球**，仅包含 C、H₂O、O₂，无初始 CO₂。
- 手牌默认为氧气 (O₂)。
- 轨道有明显起点（球进入）和终点（CO₂ 危险端）。

## 🚀 如何运行

1. 将项目中的 `index.html` 文件用浏览器打开（推荐 Chrome / Edge / Firefox 最新版）。
2. 无需安装任何依赖，纯前端 HTML5 Canvas 实现。
3. 游戏将在 5 分钟内呈现完整可玩循环。

---

## 🧠 设计哲学

- **祖玛的轨道消除**提供直观的插入-移动-消除节奏。
- **化学主题**赋予反应以因果逻辑：  
  `燃烧制造压力 → 光合作用缓解压力 → 三消提供瞬时调控空间`  
- 玩家必须不断在“制造氧气”、“消除碳”、“阻止 CO₂ 前进”之间做出实时决策。
